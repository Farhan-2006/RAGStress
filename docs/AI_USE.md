# AI-use declaration
OpenAI Codex assisted in code, frontend design, debugging, calibration harness, experiment scripts and technical documentation. Public pretrained models generate drafts, embed text and classify evidence; these outputs are approximate and explicitly labelled. Retrieval, metrics and experimental orchestration are implemented inspectably in this repository. No existing published project was copied.

Numerical results come only from executed experiments. No human annotation, team contribution, video, deployment or scientific correctness was fabricated. Human review and final academic submission remain team responsibilities.
