# Interface
The result leads with submitted input, final answer, decision and reason. Claims & evidence separates strong support, moderate support, contradiction and inconclusive passages. Stress tests shows only counter-search and wording variants. Retrieval details exposes actual ranks, scores, passages and postings. Evaluation distinguishes dataset retrieval from answer confidence.

Missing verification is unavailable, not zero truth. Every result remains tied to its submitted settings; failed attempts retain a labelled previous result. Source selectors replace unreliable cross-tab anchors. Escaped exact-term highlights preserve evidence text. Markdown/JSON exports describe the exact completed run and omit configuration secrets.
