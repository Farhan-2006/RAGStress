# Experimental protocol
The recorded 50-case experiment below is historical and describes the short-answer revision. The subsequent single-paragraph revision has only functional checks and real question sanity runs so far; its end-to-end metrics have not been measured. The evaluated source/results snapshot is preserved separately. Do not use the historical values as paragraph-revision performance claims.

Phase 1: 80 seeded original-training rationale pairs (40 support / 40 contradiction). The old policy obtained 20 correct decisive predictions; threshold-grid calibration selected moderate support .60 and contradiction .90. The production classifier also confirms contradiction in passage context and checks semantic/entity alignment; its actual training diagnosis and sanity runs are saved separately.

Strong support remains .80. Lexical alignment becomes secondary: weighted coverage .15 OR semantic cosine .40, with numbered-entity mismatches still blocked. Moderate support is qualified. Severe wording variation uses .15 rather than treating every overlap loss as a correctness failure. No decision-frequency target is used.

Phase 2 freezes runtime hashes before selecting a 50-example original-dev set. The test release has no stance gold. Sampling is stratified, seeded and explicit; this is an exploratory controlled comparison because earlier prototype development inspected some dev examples. Vanilla/full use the same actual ranked passages and deterministic generator configuration. Model loading and indexing are excluded from warm latency; timed methods clear query, NLI and semantic caches between systems. System order is counterbalanced.

Gold document/rationale recall is distinct from generated-claim support. Model-based support rates reuse the local verifier and can be circularly favorable to its own decisions; independent human judgments are pending. Answer-stance alignment is explicitly an automated diagnostic, not proof of free-form answer correctness. No exhaustive labels exist for every generated claim or candidate passage. Missing metrics stay unavailable. All raw records, component comparison, tests, plots and final conclusions are generated by run_evaluation.py.

Executed: 50/50 fixed examples, 25 SUPPORT and 25 CONTRADICT; all three systems completed, with identical initial ranked passages and drafts asserted. Full-system decisions: KEEP 26, QUALIFY 6, REWRITE 16, ABSTAIN 2. Counter-search finds calibrated contradictory passages for 17/64 audited claims; 16/50 unqualified drafts are challenged under the declared operational definition. Mean original-to-variant Jaccard .73193; pairwise mean .72134, median .66667, minimum .11111; two of 300 individual pairs are below .15, but no query's mean is below .15.

Common-NLI groundedness: vanilla 44/67 claims, full 54/62. Claim support: 49/67 versus 60/62. Unsupported: 8/67 versus 2/62. Fully supported answer incidence: 27/50 versus 40/50 (exact McNemar p=.00024414; paired bootstrap change 95% interval [.14,.38]). Automated stance agreement: 21/50 versus 26/50 (p=.33231, not significant). Latency delta: 10.75079s, paired-bootstrap 95% interval [9.07090,12.71032]. Primary free-form correctness remains unavailable.

Verification-only equals full aggregate support/groundedness/coverage/stance agreement, with lower mean latency (8.98307s versus 11.83354s). Gold refuting-source detection is 10/25 for initial retrieval and initial-plus-counter retrieval. The two stress tests therefore expose inspectable diagnostics without an established incremental quality gain on this subset. Gold-SUPPORT diagnostic agreement drops 15/25 -> 9/25; gold-CONTRADICT rises 6/25 -> 17/25. Do not suppress this directional regression.

A post-hoc reporting correction changed the expanded refutation diagnostic from counter-only to initial-plus-counter evidence. Both raw components are retained. No frozen runtime, answer, decision, or measured timing changed. All modes used actual local FLAN generation, with no API key or external generation in the comparison.
